US配列キーボードに半角/全角キーがない問題を、` キーで解決した話

2026年11月16日 ・ Windows 10 / 11 ・ Rust

困っていたこと

US配列（英語配列）のキーボードには、日本語キーボードにある半角/全角キーがありません。Windows で日本語入力（IME）を切り替える標準の方法は Alt + ` の同時押しです。これが地味に押しにくい。左上の端にある `（バッククォート）と Alt を同時に狙う操作を、文章を書くたびに何十回も繰り返すことになります。

60%キーボードのような小型の英語配列だと、さらに事情は悪くなります。「日本語入力の切り替えだけ、半角/全角キーと同じ感覚で1キーにしたい」。欲しいのはそれだけでした。

既存の方法を全部試して分かったこと

方法結果
Windows 標準（Alt + `）設定ゼロだが、毎回2キーの同時押しになる
Microsoft IME のキーカスタマイズ修飾キーとの組み合わせには割り当てられるが、単独キーのトグルにはできない
PowerToys Keyboard Manager汎用には高機能だが、この入れ替えだけのために大きなユーティリティを常駐させることになる。IME切り替えキーのリマップには相性問題の報告もある
AutoHotkey柔軟だが、スクリプトの作成・保守と本体の常駐が必要
レジストリの Scancode Mapこの入れ替えは実現できない（後述）

一番意外だったのが Scancode Map です。Windows 標準の仕組みで再起動すれば効くので最初に試したのですが、入れ替えできるのは「単独キー同士」だけでした。` 単独と Alt + ` のように、「単独キー」と「修飾キーとの組み合わせ」の入れ替えは、仕組み上できない。これは実際に試して初めて分かりました。

つまり、この入れ替えをやるには「キー入力をフックして、押された組み合わせを見てから別の入力に置き換える」常駐プログラムが要ります。やることが1つに決まっているなら、汎用ツールではなく単機能の小さな道具を作るのが早い。そうして作ったのが key-remap です。

作ったもの：key-remap

変えるのは2つだけです。それ以外は一切触りません。

入力導入前導入後
`` が入力される日本語入力のオン/オフ（半角/全角キー相当）
Alt + `日本語入力のオン/オフ` が入力される
Shift + `~ が入力されるそのまま
Ctrl + ` など各アプリのショートカットそのまま

exe を実行するだけで有効になり、あわせて自動起動も登録されます。インストール不要、単一ファイル 113 KB、常駐時のメモリ使用量は約 1 MB です。

実装の勘所

作り自体は Rust で、低レベルキーボードフック（WH_KEYBOARD_LL）で ` のキー（VK_OEM_3）を拾い、SendInput で置き換える、という素直なものです。ただ、実際に使い物にするまでにいくつか工夫が要りました。

  • 入力言語はフォーカス中のウィンドウから判定する：アクティブな入力言語は、前面ウィンドウのスレッドから取得します（GetGUIThreadInfo + GetKeyboardLayout）。これでストアアプリ等でも正しく判定できます。
  • 言語ごとに「切り替えキー」が違う：日本語には半角/全角キー、韓国語には 한/영 キーという専用キーがありますが、他の言語には専用キーがありません。そこで v0.3.0 から3分岐にしました。日本語なら半角/全角キー（vkF3 / sc029）、韓国語なら 한/영 キー（vk15）、それ以外はトップレベルウィンドウへ WM_INPUTLANGCHANGEREQUEST で次の言語（HKL_NEXT）を明示する。最後のは Alt + Shift の「次の言語へ」を、対象ウィンドウ限定で確実に行う方法です。
  • バッククォートの入力で Alt をマスクする：Alt + ` で ` の文字を送るとき、そのままではアプリが Alt ショートカットと誤認します。Unicode 文字として送出し、その間 Alt の影響を抑えることで回避しています。
  • 長押しの扱いを分ける：` の長押しでは切り替えは1回だけ（押しっぱなしでオン/オフを繰り返さない）。Alt + ` の長押しは通常のキーと同じく連続入力にします。
  • 自動起動は自分で登録し直す：起動時に HKCU の Run キーへ自分のパスを書き込むので、exe を移動しても次回起動時に新しい場所で登録し直されます。解除は key-remap.exe --uninstall です。

外部ライブラリは使っていません（raw Win32 FFI）。ポーリングもタイマーもなく、待機中はメッセージループで眠っているだけなので、CPU は使いません。

向いていない人

key-remap はトグル式だけです。IME の「オン専用キー」と「オフ専用キー」を別々に割り当てたい場合は、AutoHotkey 系（alt-ime-ahk など）の方が向いています。また、管理者権限で実行されているウィンドウの上では、ユーザーレベルのフックでは入力を拾えません（これは Windows の仕様で、その場合は key-remap 側も管理者権限で実行してください）。

逆に、「変えたいのはこの1点だけ」「設定画面を開きたくない」という人には、単機能であることがそのまま利点になると思います。

まとめ

US配列キーボードの日本語入力切り替えは、小さいけれど毎日触る不便です。既存の方法では埋まらなかった「` 単独を半角/全角キーにする」という一点を、113 KB の単機能ツールで埋めました。同じことで引っかかっている人の参考になれば幸いです。

多言語を行き来する人向けには、` キー単押しで入力言語を切り替えるページも用意しています。
