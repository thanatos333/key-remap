On a US keyboard, toggle Japanese input with a single ` key.

If you use a US-layout keyboard on Windows, turning Japanese input on and off takes Alt + ` — both hands, every time, because there is no Hankaku/Zenkaku key like on a Japanese keyboard. It gets old fast.

key-remap is a small resident program that swaps the roles of these two keys. One press of ` toggles input, and the backquote itself moves to Alt + `. I built it for my own daily use and published it in case it helps anyone with the same annoyance.

02

How to use

Download, run, done. There are no settings to fiddle with.

1

Download and put it anywhere

Download key-remap.exe and drop it wherever you like.

2

Run it

Double-click to run. The swap takes effect immediately, and the tool registers itself for auto-start at the same time, so from your next logon it starts on its own — no need to launch it again.

3

To stop

End key-remap in Task Manager. To also remove the auto-start registration, run key-remap.exe --uninstall first.

Auto-start registration writes the exe's own path to HKCU\Software\Microsoft\Windows\CurrentVersion\Run in the registry. If you move the exe, it re-registers the new location the next time it runs.

03

Details and notes

A few things worth knowing before you use it.

  • Runs on Windows 10 / 11. Tested with Microsoft IME and Google Japanese Input.
  • Resident memory use is about 1 MB. It only does work when a key is pressed, so it uses no CPU while idle.
  • It cannot see keystrokes in windows that run with administrator privileges — that is a Windows restriction. If you need it there, run key-remap itself as administrator.
  • Holding ` toggles only once (it will not flip on/off repeatedly). Holding Alt + ` repeats the backquote like a normal key.
  • Written in Rust with no external libraries. It uses a low-level keyboard hook and SendInput to do the swap. Source is on GitHub under the MIT License.
04

FAQ

These might answer it before you have to ask.

How do I toggle the Japanese IME on a US (English) keyboard?

By default on Windows it is Alt + ` together. With key-remap running, a single press of ` toggles Japanese input instead.

Does it work on keyboards without a Hankaku/Zenkaku key?

Yes. key-remap was made exactly for US-layout keyboards that lack that key; the ` key takes its place.

Can I still type a backquote (`) and tilde (~)?

Yes. The backquote moves to Alt + `, and the tilde stays on Shift + `, exactly as before.

Is key-remap free?

Yes, it is free, and the source code is published under the MIT License.

Do I need to install it?

No. Just run the exe. On first launch it also registers itself for auto-start, so from the next logon it starts on its own.

What are the system requirements?

Windows 10 or 11, with a Japanese IME such as Microsoft IME or Google Japanese Input.

Just try running it

If it is not for you, quit it and delete the file. That is all.
