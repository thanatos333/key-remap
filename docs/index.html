FAQ

よくある質問

US配列（英語配列）キーボードで日本語入力（IME）を切り替えるには？

Windows の標準では Alt + `（バッククォート）が IME のオン/オフ切り替えですが、両手が必要で面倒です。key-remap を使うと、` キー単独で切り替えられるようになります。

半角/全角キーがないキーボードでも使えますか？

はい。むしろ半角/全角キーのない US配列キーボードのために作られたツールです。` キーが半角/全角キーの代わりになります。

バッククォート（`）やチルダ（~）は打てなくなりますか？

打てます。バッククォートは Alt + ` で入力でき、チルダは Shift + ` で従来どおり入力できます。

key-remap は無料ですか？

無料です。ソースコードも MIT ライセンスで公開されているオープンソースソフトウェアです。

インストールやレジストリの変更は必要ですか？

不要です。key-remap.exe を実行するだけで動作し、レジストリは変更しません。アンインストールはプロセスを終了してファイルを削除するだけです。

対応環境を教えてください。

Windows 10 / 11 と、Microsoft IME や Google 日本語入力などの日本語 IME で動作します。常駐時のメモリ使用量は約1MB、実行ファイルは104KBです。
