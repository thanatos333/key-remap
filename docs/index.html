` key-remap
キーの動き 使い方 FAQ GitHub

US配列（英語配列）キーボードで、
` キーひとつで日本語入力に切り替える。

US配列のキーボードを Windows で使っていると、日本語入力（ローマ字入力）のオン/オフは Alt + ` の同時押しになります。半角/全角キーのある日本語キーボードと違って、1回ごとに両手が要るのが地味に面倒でした。

key-remap は、この2つのキーの役割を入れ替える小さな常駐プログラムです。` を1回押せば入力が切り替わり、バッククォート自体は Alt + ` で入力します。自分が毎日使うために作ったものですが、同じ不便を感じている人の役に立てばと思い公開しています。

02

使い方

ダウンロードして実行するだけです。面倒な設定はありません。

1

ダウンロードして置く

key-remap.exe をダウンロードして、好きな場所に置きます。

2

実行する

ダブルクリックで実行します。この時点で入れ替えが有効になり、あわせて自動起動の登録も行われます。次回のログインからは自動で起動するので、毎回実行する必要はありません。

3

やめたいとき

タスクマネージャーで key-remap を終了してください。自動起動も解除する場合は key-remap.exe --uninstall を実行してから終了します。

自動起動の登録は、レジストリの HKCU\Software\Microsoft\Windows\CurrentVersion\Run に自分のパスを書き込む方法で行います。exe を移動しても、次に起動したときに新しい場所で登録し直します。

03

仕様と注意

使う前に知っておいてほしいことをまとめました。

  • 対応 OS は Windows 10 / 11 です。Microsoft IME、Google 日本語入力で動作を確認しています。
  • 常駐時のメモリ使用量は約 1 MB です。キー入力があったときだけ処理が走るので、待機中に CPU を使うことはありません。
  • 管理者権限で実行されているウィンドウの上ではキー入力を拾えません。これは Windows の仕様によるもので、その場合は key-remap 側も管理者権限で実行してください。
  • ` の長押しでは切り替えは1回だけです（押しっぱなしでオン/オフを繰り返しません）。Alt + ` の長押しは、通常のキーと同じく連続入力になります。
  • 実装は Rust で、外部ライブラリは使っていません。低レベルキーボードフックで入力を受け取り、SendInput で置き換えています。ソースコードは GitHub で公開しています（MIT ライセンス）。
04

よくある質問

問い合わせの前に、こちらで解決するかもしれません。

US配列（英語配列）キーボードで日本語入力（IME）を切り替えるには？

Windows の標準では Alt と ` の同時押しが切り替えですが、key-remap を実行しておくと ` キーを1回押すだけで切り替わるようになります。ローマ字入力と半角英数の切り替えが、半角/全角キーと同じ感覚でできるようになります。

USキーボードで日本語入力に切り替えできないのはなぜ？

USキーボードには半角/全角キーがないため、日本語キーボードのように1つのキーでは切り替えられないのが理由です。Windows 標準の切り替えキーは Alt + ` です。これが押しにくい、届きにくいと感じる場合は、key-remap を実行しておけば ` キー単独で切り替えられます。

半角/全角キーがないキーボードでも使えますか？

はい。半角/全角キーのない US配列キーボードのために作ったツールで、` キーがその代わりになります。

60%キーボードでも使えますか？

使えます。半角/全角キーのない小型の英語配列キーボードでも、` キーが切り替えキーになります。Esc と兼用で Fn キーとの同時押しで ` を入力する機種でも、その入力を拾って切り替えます。

バッククォート（`）やチルダ（~）は打てなくなりますか？

打てます。バッククォートは Alt + ` 、チルダは Shift + ` で、これまでどおり入力できます。

key-remap は無料ですか？

無料です。ソースコードも MIT ライセンスで公開しています。

インストールは必要ですか？

必要ありません。exe を実行するだけです。初回起動時に自動起動の登録も済むので、次回のログインからは自動で起動します。

Windows 11 でも使えますか？設定は必要ですか？

はい、Windows 11 と Windows 10 に対応しています。Windows 側の設定変更は不要で、exe を実行するだけです。英語配列キーボードを Windows 11 で使うときの日本語入力切り替えが、そのまま楽になります。

対応環境を教えてください。

Windows 10 / 11 で、Microsoft IME や Google 日本語入力などの日本語 IME と組み合わせて使えます。
