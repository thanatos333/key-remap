` key-remap
키 동작 사용법 자주 묻는 질문 GitHub

미국식 키보드에서 사라진 한/영 키와 반각/전각 키를, ` 키 하나로 되돌립니다.

Windows에서 미국식 키보드를 쓰면, 한국어 키보드에 있던 한/영 키도, 일본어 키보드에 있던 반각/전각 키도 없습니다. 한/영 전환은 오른쪽 Alt나 Win + Space로 대신하고, 일본어 입력 켜고 끄기는 Alt + `(` 는 Esc 아래에 있는 키) 조합 키로 대신하게 됩니다. 어느 쪽도 키 하나로는 끝나지 않습니다.

key-remap은 지금 켜져 있는 입력 언어를 보고 ` 키의 역할을 바꿔 주는 작은 상주 프로그램입니다. 한국어가 켜져 있으면 ` 가 한/영 키가 되고, 일본어가 켜져 있으면 반각/전각 키가 됩니다. 백쿼트 자체는 Alt + ` 로 입력합니다. 사라진 전환 키를 언어마다 되돌려 주는 도구로, 매일 직접 쓰려고 만들었다가 같은 불편을 겪는 분들께도 도움이 될까 싶어 공개합니다.

02

사용법

다운로드, 실행, 끝. 조정할 설정이 없습니다.

1

다운로드해서 원하는 곳에 두기

key-remap.exe를 다운로드해 원하는 위치에 둡니다.

2

실행하기

더블클릭으로 실행합니다. 교환이 즉시 적용되고 자동 시작도 등록되어, 다음 로그인부터는 스스로 실행되니 매번 켤 필요가 없습니다.

3

중지하려면

작업 관리자에서 key-remap을 종료합니다. 자동 시작 등록까지 지우려면 먼저 key-remap.exe --uninstall 을 실행하세요.

자동 시작은 exe 자신의 경로를 레지스트리 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 에 기록하는 방식으로 등록됩니다. exe를 옮겨도 괜찮습니다. 다음 실행 때 새 위치로 다시 등록합니다.

03

상세 및 주의 사항

사용하기 전에 알아 두면 좋은 것들입니다.

  • Windows 10 / 11을 지원합니다. Microsoft IME와 Google 일본어 입력에서 동작을 확인했습니다.
  • ` 키는 지금 켜진 입력 언어를 자동으로 보고 동작합니다. 일본어면 반각/전각 키, 한국어면 한/영 키로 동작하고, 그 밖의 언어에서는 다음 입력 언어로 전환합니다. 입력 언어가 하나뿐인 환경에서는 ` 가 그대로 문자로 입력됩니다.
  • 상주 메모리는 약 1 MB. 키를 누를 때만 처리하고, 대기 중에는 CPU를 쓰지 않습니다.
  • 관리자 권한으로 실행 중인 창의 키 입력은 읽을 수 없습니다. Windows의 제한입니다. 그런 창에서도 쓰려면 key-remap도 관리자 권한으로 실행하세요.
  • ` 를 길게 눌러도 전환은 한 번만 일어납니다(반복해서 켜고 꺼지지 않습니다). Alt + ` 를 길게 누르면 일반 키처럼 연속 입력됩니다.
  • Rust로 만들었고 외부 라이브러리를 쓰지 않습니다. 저수준 키보드 후크로 입력을 받아 SendInput으로 바꿔 보냅니다. 소스 코드는 GitHub 에 MIT 라이선스로 공개되어 있습니다.
04

자주 묻는 질문

문의하기 전에, 여기서 해결되지 않는지 먼저 확인해 보세요.

미국식(영문) 키보드에서 일본어 IME는 어떻게 전환하나요?

Windows 기본값은 Alt + ` 동시 입력입니다. key-remap을 실행하면 ` 한 번으로 일본어 입력을 전환할 수 있어, 로마자 입력과 반각 영숫자 사이를 반각/전각 키처럼 오갈 수 있습니다.

미국식 키보드에서 일본어 입력으로 잘 전환되지 않는 이유는 무엇인가요?

미국식 키보드에는 반각/전각 키가 없어서, 일본어 키보드처럼 키 하나로 전환할 수 없기 때문입니다. Windows의 표준 단축키는 Alt + ` 입니다. 누르기 어렵거나 손이 닿기 힘들다면 key-remap으로 ` 한 번에 전환할 수 있습니다.

반각/전각 키가 없는 키보드에서도 쓸 수 있나요?

네. 반각/전각 키가 없는 미국식 키보드를 위해 만든 도구로, ` 키가 그 역할을 대신합니다.

60% 키보드에서도 쓸 수 있나요?

네. 반각/전각 키가 없는 작은 영문 키보드에서 ` 키가 전환 키가 됩니다. ` 가 Esc와 함께 있어 Fn과 함께 입력하는 기종에서도, 그 입력을 읽어 전환합니다.

백쿼트(`)와 틸드(~)도 계속 입력할 수 있나요?

네. 백쿼트는 Alt + ` 로, 틸드는 Shift + ` 로, 지금까지와 같습니다.

key-remap은 무료인가요?

네, 무료입니다. 소스 코드도 MIT 라이선스로 공개되어 있습니다.

설치가 필요한가요?

필요 없습니다. exe를 실행하기만 하면 됩니다. 처음 실행할 때 자동 시작 등록도 함께 이루어져, 다음 로그인부터는 자동으로 실행됩니다.

Windows 11에서도 되나요? 설정을 바꿔야 하나요?

네, Windows 11과 Windows 10을 지원합니다. Windows 설정을 변경할 필요 없이 exe를 실행하면, 영문 키보드에서 일본어 입력 전환이 바로 편해집니다.

시스템 요구 사항은 무엇인가요?

Windows 10 또는 11, 그리고 Microsoft IME나 Google 일본어 입력 같은 일본어 IME입니다.

key-remap은 키맵 편집기인가요?

아닙니다. key-remap은 범용 키맵 편집기가 아니며, 임의의 키를 다시 매핑할 수도 없습니다. 키맵 변경은 딱 하나, ` 키와 Alt + ` 의 역할 맞바꾸기뿐이며 설정 화면도 없습니다. 여러 키를 바꾸려면 PowerToys Keyboard Manager 같은 범용 도구가 더 적합합니다.

한국어 입력과 일본어 입력을 자주 오가는데, 누를 키를 줄일 수 있나요?

양쪽 다 줄어듭니다. 한국어가 켜져 있을 때는 ` 한 번이 한/영 키가 되고, 일본어가 켜져 있을 때는 ` 한 번이 반각/전각 키가 됩니다. 언어를 오가는 Win + Space만 그대로지만, 각 언어 안에 들어간 뒤의 전환은 양쪽 다 조합 키 없이 끝납니다.

레지스트리를 건드리기 싫고 PowerToys도 설치하기 싫습니다. 더 간단한 방법이 있나요?

key-remap은 설치가 필요 없습니다. 다운로드한 exe를 실행하기만 하면 됩니다. 키보드 매핑용 레지스트리(Scancode Map)를 건드리지 않고, 자동 시작만 현재 사용자 범위에 등록합니다. 제거할 때는 key-remap.exe --uninstall 을 실행하세요.

미국식 키보드에는 반각/전각 키가 없는데, 일본어 입력은 어떻게 켜고 끄나요?

Windows에 내장된 대체 방법은 Alt + `, 즉 Esc 아래에 있는 그 키입니다. key-remap을 실행한 뒤에는 ` 한 번으로 일본어 입력을 켜고 끌 수 있어, 두 키를 동시에 누를 필요가 없습니다.

이렇게 전용 키가 없는 문제는 다른 언어에도 있나요?

네. 그런데 살펴보면 입력 전환 전용 키를 가진 언어는 일본어(반각/전각)와 한국어(한/영)가 사실상 전부입니다. 미국식 키보드는 이 두 키를 모두 빼놓았고, key-remap은 둘 다 다룹니다. 전용 키가 없는 다른 언어가 켜져 있을 때는 ` 가 다음 입력 언어로 넘어가는 전환 키로 동작합니다.

한 번에 IME를 전환하는 방법은 몇 가지가 있습니다. 흔한 방법들을 비교했으니 자신에게 맞는 것을 고르세요.

방법필요한 것비고
Windows 기본아무것도 필요 없음 — Alt + ` 를 그대로 사용설정은 없지만, 영원히 두 키 조합을 매번 눌러야 합니다
Microsoft 일본어 IME의 키 설정IME 설정에서 "키 및 터치 사용자 지정" 열기Ctrl + Space 같은 조합 키에는 IME 켜기/끄기를 지정할 수 있지만, 단일 키로는 지정할 수 없습니다
PowerToys Keyboard ManagerPowerToys를 설치하고 매핑 설정기능이 완전한 범용 키보드 매핑 도구입니다. 하지만 이 한 가지 교환만을 위해서는 설치가 크고, 설정이 큰 도구 안에 있습니다. 또 Keyboard Manager로 IME 전환 키를 다시 매핑할 때의 호환성 문제가 PowerToys 공식 저장소에 기록되어 있습니다
AutoHotkeyAutoHotkey를 설치하고 짧은 스크립트 작성매우 유연하지만, 스크립트를 직접 쓰고 유지해야 하고 AutoHotkey 런타임이 상주합니다
레지스트리(Scancode Map)레지스트리를 편집하고 재부팅Windows 내장 방식이지만 일반 키끼리의 교환만 가능합니다. 일반 키와 Alt + 키 조합은 맞바꿀 수 없어 이 교환은 할 수 없습니다(key-remap 개발 과정에서 확인)
key-remap113 KB exe를 실행할 뿐단일 용도: 이 교환 하나, 설정 없음, 상주 약 1 MB

이미 PowerToys나 AutoHotkey로 다른 매핑을 쓰고 있다면, 이 교환을 거기에 더하는 것도 충분히 합리적입니다. key-remap은 "바꾸고 싶은 게 이 한 가지뿐"인 경우를 위한 도구입니다.
