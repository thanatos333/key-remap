` key-remap
按鍵方式 使用方法 常見問題 GitHub

在美式鍵盤上，用單一 ` 鍵切換日文輸入。

在 Windows 上使用美式鍵盤時，開關日文輸入需要同時按 Alt + `（` 就是 Esc 下面那個鍵），每次都要兩隻手，因為美式鍵盤沒有日式鍵盤上的半形/全形鍵。用久了真的很煩。

key-remap 是一款小巧的常駐程式，交換這兩個鍵的角色。按一下 ` 就能切換輸入，反引號本身則改到 Alt + `。可以把它想成是對鍵盤對應（keymap）的一行修改：只有這兩個項目互換位置，其他部分完全不動。這是我為了自己每天使用而做的工具，想說有相同困擾的人或許也用得上，就公開了。

02

使用方法

下載、執行、完成。沒有任何設定要調。

1

下載，放在任何地方

下載 key-remap.exe，放在你喜歡的位置即可。

2

執行它

雙擊執行。交換立即生效，同時工具會把自己註冊為自動啟動，下次登入起會自己啟動，不必每次手動開。

3

要停止時

在工作管理員中結束 key-remap。若要一併移除自動啟動註冊，先執行 key-remap.exe --uninstall。

自動啟動的註冊方式，是把 exe 自己的路徑寫入登錄檔的 HKCU\Software\Microsoft\Windows\CurrentVersion\Run。移動 exe 也沒關係，下次啟動時會以新位置重新註冊。

03

詳細與注意事項

使用前值得知道的幾件事。

  • 支援 Windows 10 / 11。已在 Microsoft IME 與 Google 日文輸入法上確認運作。
  • 常駐記憶體約 1 MB。只有在按鍵時才處理，待機時不耗 CPU。
  • 無法讀取以系統管理員權限執行的視窗中的按鍵——這是 Windows 的限制。若需要在那種視窗使用，請讓 key-remap 也以系統管理員權限執行。
  • 長按 ` 只會切換一次（不會反覆開關）。長按 Alt + ` 則和一般按鍵一樣連續輸入。
  • 以 Rust 撰寫，不使用外部函式庫。使用低階鍵盤鉤子接收輸入，再以 SendInput 替換。原始碼在 GitHub 以 MIT 授權公開。
04

常見問題

在詢問之前，先看看這裡能不能解決。

在美式（英文）鍵盤上，要如何切換日文 IME？

Windows 預設是同時按 Alt + `。執行 key-remap 之後，按一下 ` 就能切換日文輸入，在羅馬字輸入與半形英數之間切換，就像半形/全形鍵一樣。

為什麼在美式鍵盤上無法順利切換到日文輸入？

因為美式鍵盤沒有半形/全形鍵，不像日式鍵盤可以用單一按鍵切換。Windows 的標準快速鍵是 Alt + `。如果覺得難按或不好觸及，key-remap 讓你按一下 ` 就能切換。

沒有半形/全形鍵的鍵盤也能用嗎？

可以。key-remap 正是為了沒有這個鍵的美式鍵盤而做的，由 ` 鍵來代替它。

60% 鍵盤也能用嗎？

可以。在沒有半形/全形鍵的小型英文鍵盤上，` 鍵就是切換鍵。若是 ` 與 Esc 共用、需要搭配 Fn 輸入的機種，key-remap 也能讀到那個輸入並進行切換。

還能輸入反引號（`）和波浪號（~）嗎？

可以。反引號改到 Alt + `，波浪號維持 Shift + `，和以前一樣。

key-remap 是免費的嗎？

是免費的，原始碼也以 MIT 授權公開。

需要安裝嗎？

不需要。執行 exe 即可。首次啟動時會一併完成自動啟動註冊，下次登入起會自動啟動。

Windows 11 也能用嗎？需要改設定嗎？

可以，支援 Windows 11 與 Windows 10。不需要變更任何 Windows 設定，執行 exe 即可，在英文鍵盤上切換日文輸入馬上變輕鬆。

系統需求是什麼？

Windows 10 或 11，搭配 Microsoft IME 或 Google 日文輸入法等日文 IME。

key-remap 是鍵盤對應（keymap）編輯器嗎？

不是。key-remap 不是通用的鍵盤對應編輯器，也不能任意重新對應按鍵。它只對鍵盤對應做一項修改——` 鍵與 Alt + ` 交換角色——而且完全沒有設定畫面。如果你需要重新對應很多按鍵，PowerToys Keyboard Manager 這類通用工具會更合適。

注音輸入法和日文輸入法要一直換來換去，可以少按幾次嗎？

可以省下後半段。用 Win + Space 在注音和日文之間切換輸入法，這部分不變；但進入日文輸入法之後，原本要用 Alt + ` 在平假名和英數模式之間切換，現在只要按一下 ` 就好。來回切換時，每趟少一個組合鍵。

不想改登錄檔、也不想安裝 PowerToys，有更簡單的方法嗎？

key-remap 不需要安裝，下載後直接執行 exe 即可。它不會改動鍵盤對應的登錄檔（Scancode Map），只會把自動啟動註冊在目前使用者的範圍。要移除時，執行 key-remap.exe --uninstall 就好。

美式鍵盤沒有半形/全形鍵，要怎麼開關日文輸入？

Windows 內建的替代方式是 Alt + `，也就是 Esc 下面那個鍵。執行 key-remap 之後，按一下 ` 就能開關日文輸入，不必再同時按兩個鍵。

05

其他做法

想要一鍵切換 IME，有幾種做法。以下是常見方式的比較，方便你挑選適合自己的。

做法需要什麼備註
Windows 預設什麼都不用——照常用 Alt + `零設定，但永遠是兩鍵組合，每次都要按
微軟日文輸入法的快速鍵設定在 IME 設定中開啟「鍵盤與觸控自訂」可以把 IME 開關指定給 Ctrl + Space 這類組合鍵，但不能指定給單獨一個按鍵
PowerToys Keyboard Manager安裝 PowerToys 並設定對應功能完整的通用鍵盤對應工具。但只為這一個交換來說，安裝體積偏大，設定也藏在大型工具裡面。另外，Keyboard Manager 重新對應 IME 切換鍵時有相容性問題，在 PowerToys 官方儲存庫中有紀錄
AutoHotkey安裝 AutoHotkey 並寫一小段腳本非常有彈性——但腳本要自己寫、自己維護，AutoHotkey 執行環境也會常駐
登錄檔（Scancode Map）編輯登錄檔並重新開機Windows 內建，但只能把一個普通鍵換成另一個普通鍵，無法把普通鍵與 Alt + 鍵的組合互換，所以做不到這項交換（開發 key-remap 時確認過）
key-remap執行一個 112 KB 的 exe單一用途：只有這項交換、沒有設定、常駐約 1 MB

如果你已經在用 PowerToys 或 AutoHotkey 做其他對應，把這項交換加在那邊也完全合理。key-remap 是為了「只想改這一項」的情況而存在的。
