キー1つで、入力言語を切り替える。

2つ以上の言語を行き来する人ならおなじみの、Alt + Shift や Win + Space の同時押し。1日に何十回も繰り返していると、押し損ねて違う言語のまま文を打っていた、ということになります。集中も途切れます。

key-remap は、この切り替えを Esc の下にある ` キー1つに移す小さな常駐プログラムです。押すたびに次の入力言語へ切り替わり、バッククォートの文字自体は Alt + ` で打てるので、何も失いません。113 KB の exe 1つ、インストール不要。自分の多言語環境のために作ったものを公開しています。

02

使い方

ダウンロードして、実行するだけ。設定項目はありません。

1

ダウンロードして好きな場所に置く

key-remap.exe をダウンロードして、好きなフォルダに置きます。

2

実行する

ダブルクリックで実行します。言語の切り替えは即座に有効になり、同時に自動起動も登録されるので、次回ログオンからは自動で起動します。もう一度起動し直す必要はありません。

3

止める／アンインストール

タスクマネージャーで key-remap を終了します。自動起動の登録も消す場合は、先に key-remap.exe --uninstall を実行してからファイルを削除します。

自動起動の登録は、レジストリの HKCU\Software\Microsoft\Windows\CurrentVersion\Run に exe 自身のパスを書く仕組みです。管理者権限は関与しません。exe を移動した場合は、次回実行時に新しい場所で登録し直します。

03

詳細と注意事項

使う前に知っておくといいことです。

  • Windows 10 / 11 で、Windows が提供する入力言語全般に対応します。日本語・韓国語の特例を除き、言語ごとの特別な処理はありません。
  • 入力言語が1つだけの環境では、` は今まで通りバッククォートを入力します。切り替え先があるときだけ転用されます。
  • バッククォート自体は Alt + ` へ移り、チルダは Shift + ` のまま変わりません。
  • IME の中でのモード切り替えには干渉しません。たとえば中国語 IME で Shift を押して中国語入力と英語入力を切り替える動作は、今まで通りです。
  • Windows の設定で ` 自体を言語切り替えのホットキーにしている場合（タイ語環境でよくある設定）でも、` で切り替わることに変わりはありません。key-remap が同じ「次の言語へ」の切り替えを行うためです。
  • ` を長押ししても切り替えは1回だけです。言語が高速で巡回することはありません。
  • 管理者権限で動いているウィンドウのキー入力は拾えません（Windows の制限）。必要な場合は key-remap 自体も管理者として実行してください。
  • 常駐メモリは約 1 MB です。キーが押されたとき以外は仕事をしないので、アイドル時の CPU 使用率はゼロです。
  • Rust 製・外部ライブラリなし。低レベルキーボードフックで切り替えを行います。ソースは GitHub で MIT ライセンス公開です。
04

FAQ

聞かれる前に答えておきます。

どの言語でも使えますか？

はい、基本的には。key-remap 自体は言語の処理をせず、` を押すたびに Windows へ「次の入力言語へ」と頼むだけです。Alt + Shift が行う切り替え、そのものです。ロシア語・アラビア語・ヘブライ語・ヒンディー語・ギリシャ語・ウクライナ語・タイ語・ベトナム語・中国語など、Windows の言語リストに入っている言語はすべて順送りで切り替わります。日本語と韓国語だけは特例で、` がその言語の専用キー（半角/全角キー、한/영 キー）として働きます。

Win + Space と何が違うのですか？

Win + Space は Windows 標準の切り替えで、言語パネルが開き、Win を押しながら Space で選びます。key-remap はパネルも2つ目のキーもなしで、` 1回ですぐに切り替わります。Win + Space で不満がなければ、正直このツールは要りません。1日に何十回も切り替えるので1キーにしたかった、という人のためのものです。

Caps Lock を切り替えキーにする方法と何が違うのですか？

AutoHotkey やレジストリ変更で Caps Lock を切り替えに使うのは定番の方法で、それ自体は有効です。ただ Caps Lock は状態を持つキーなので、ランプやオン/オフの状態と頭の中がずれやすく、キーを1つ失うか、スクリプトの管理が要ります。key-remap は、ふだん文字として打つ機会の少ない ` を使い、文字自体は Alt + ` に残します。スクリプトもレジストリ編集も不要で、小さな exe 1つだけです。

言語を3つ以上入れているとどうなりますか？

押すたびに、インストール済みの言語を Alt + Shift と同じ順序で1つずつ進みます。3言語なら A → B → C → A の順送りです。2言語だけなら、結果として往復のトグルになります。

` の文字は打てなくなりますか？

打てます。バッククォートは Alt + ` へ移り、チルダは Shift + ` のまま変わりません。また、入力言語が1つだけの環境では ` はそもそも転用されず、従来通りバッククォートが入力されます。

管理者権限は要りますか？

要りません。通常のユーザー権限で動き、自動起動の登録も自分のアカウント（HKCU）の範囲だけです。インストール作業も管理者プロンプトもありません。Windows の仕様上の制限として、管理者権限で動いているウィンドウのキー入力には、key-remap 自体も管理者として実行しないと届きません。

ゲームや全画面アプリでも動きますか？

基本的には動きます。全画面アプリを含む、システム全体が対象です。正直な例外が2つあります。アンチチートのあるゲームでは合成キーがブロックされることがあります。また、` 自体を使うゲーム（PC ゲームの開発者コンソールなど）では、コンソールではなく言語が切り替わります。その手のゲームを遊ぶ間は key-remap を終了してください。

アンインストール方法は？

key-remap.exe --uninstall を1回実行して自動起動の登録を消し、動いていればタスクマネージャーで終了して、exe ファイルを削除するだけです。他に変更したものや残るものはありません。
