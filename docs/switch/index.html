Switch input languages with a single ` key.

If you type in two or more languages, you know the drill: Alt + Shift, or Win + Space — two keys at once, dozens of times a day. Miss the chord, and you have typed a whole sentence in the wrong language before you notice, and your train of thought is gone with it.

key-remap puts the switch on one key: `, the key below Esc. Each press moves to your next input language, and the backquote character itself moves to Alt + `, so nothing is lost. It is a tiny resident program — one 113 KB exe, no installation. I built it for my own multilingual desktop and published it in case it helps anyone with the same annoyance.

Each press moves one step through the languages installed in Windows: with two languages it toggles back and forth, and with three or more it cycles in the same order as Alt + Shift. Two languages get their own dedicated-key behavior instead of a language hop: in Japanese, ` presses the Hankaku/Zenkaku key and toggles the IME on and off; in Korean, it presses the Hangul key (한/영) and toggles between Hangul and Latin letters. 02

How to use

Download, run, done. There are no settings to fiddle with.

1

Download and put it anywhere

Download key-remap.exe and drop it wherever you like.

2

Run it

Double-click to run. The language switch takes effect immediately, and the tool registers itself for auto-start at the same time, so from your next logon it starts on its own — no need to launch it again.

3

To stop or uninstall

End key-remap in Task Manager. To also remove the auto-start registration, run key-remap.exe --uninstall first, then delete the file.

Auto-start registration writes the exe's own path to HKCU\Software\Microsoft\Windows\CurrentVersion\Run in the registry. No administrator rights are involved. If you move the exe, it re-registers the new location the next time it runs.

03

Details and notes

A few things worth knowing before you use it.

  • Runs on Windows 10 / 11, with any input languages Windows offers. Apart from the Japanese and Korean special cases, nothing in the tool is language-specific.
  • If only one input language is installed, ` keeps typing a backquote as usual — the key is only repurposed when there is somewhere to switch to.
  • The backquote itself moves to Alt + `, and the tilde stays on Shift + `, unchanged.
  • Switching inside an IME is untouched: for example, the Shift key that flips a Chinese IME between Chinese and English input keeps doing exactly that.
  • If your setup already uses the grave key itself as the language-switch hotkey in Windows settings — a common configuration for Thai — the key keeps its job: key-remap performs the same move to the next language when you press it.
  • Holding ` switches only once per press; it will not spin through your languages.
  • It cannot see keystrokes in windows that run with administrator privileges — that is a Windows restriction. If you need it there, run key-remap itself as administrator.
  • Resident memory use is about 1 MB. It only does work when a key is pressed, so it uses no CPU while idle.
  • Written in Rust with no external libraries. It uses a low-level keyboard hook to perform the switch. Source is on GitHub under the MIT License.
04

FAQ

These might answer it before you have to ask.

Does it work with my language?

Very likely, yes. key-remap does not handle any language itself — each press of ` simply asks Windows to move to the next installed input language, the same switch Alt + Shift performs. Russian, Arabic, Hebrew, Hindi, Greek, Ukrainian, Thai, Vietnamese, Chinese — if it is in your Windows language list, ` cycles to it. Japanese and Korean are special cases: there, ` presses the language's own dedicated key (Hankaku/Zenkaku, or the Hangul key) instead.

How is this different from Win + Space?

Win + Space is built into Windows and opens a language switcher panel; you hold Win and tap Space to pick. key-remap skips the panel and the second key: one press of ` switches immediately. If Win + Space already feels fine, you honestly do not need this tool — it exists for people who switch dozens of times a day and want it on one key.

How is it different from turning Caps Lock into a language switch?

That is the classic workaround, usually done with AutoHotkey or a registry remap. It works, but Caps Lock is a stateful key — its indicator and on/off state get confusing — and you either lose the key or maintain a script. key-remap instead uses `, a key most people rarely type, keeps the character available on Alt + `, and needs no script or registry edit: one small exe.

I use three or more languages. What happens?

Each press moves one step forward through your installed languages, in the same order as Alt + Shift — with three languages it cycles A → B → C → A. With exactly two languages, that same cycle is simply a back-and-forth toggle.

Can I still type the ` character?

Yes. The backquote moves to Alt + `, and the tilde stays on Shift + `, unchanged. And if only one input language is installed on your PC, ` is not repurposed at all — it types a backquote exactly as before.

Do I need administrator rights?

No. key-remap runs as a normal user program and registers its auto-start under your own account (HKCU), so there is nothing to install and no admin prompt. One Windows limitation: it cannot see keystrokes in windows that themselves run as administrator, unless you also run key-remap as administrator.

Does it work in games and full-screen apps?

In most cases, yes — it works system-wide, including full-screen apps. Two honest exceptions: some games with anti-cheat systems block injected keys, and games that use ` itself (the developer console in many PC games) will switch your language instead of opening the console. For those games, quit key-remap while you play.

How do I uninstall it?

Run key-remap.exe --uninstall once to remove the auto-start registration, end key-remap in Task Manager if it is still running, and delete the exe file. Nothing else is changed or left behind.

Just try running it

If it is not for you, quit it and delete the file. That is all.
